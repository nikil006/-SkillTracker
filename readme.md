# SkillTrack – Student Skill & Career Tracker

## Project Description

SkillTrack is a comprehensive web application designed to help students manage and track their skills, projects, certifications, and internships throughout their academic journey. It provides a centralized platform for students to maintain their professional profile and generate a resume automatically.

## Problem Statement

College students often struggle to:
- Keep track of all their skills and learning progress
- Maintain a record of projects, certifications, and internships
- Create an updated resume quickly when needed
- Visualize their career growth and set clear goals

SkillTrack solves these problems by providing an easy-to-use platform for comprehensive career management.

## Features

- **User Authentication**: Secure registration and login with password hashing
- **Dashboard**: Visual overview of skills, projects, certifications, and internships with progress tracking
- **Profile Management**: Complete personal and academic information management
- **Skills Tracker**: Add, edit, and delete skills with proficiency levels
- **Project Portfolio**: Showcase projects with descriptions and GitHub links
- **Certifications**: Record all professional certifications
- **Internships**: Track internship experiences and responsibilities
- **Auto-Generated Resume**: Professional resume that can be printed or saved as PDF
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Colorful gradient design with smooth animations

## Technologies Used

- **Backend**: Python, Flask
- **Database**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript
- **Icons**: Font Awesome
- **Password Security**: Werkzeug (password hashing)
